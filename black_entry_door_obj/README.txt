Черная входная дверь для Blender (OBJ)
Размеры заданы по запросу: X = 0.370 м, Y = 0.240 м, Z = 0.580 м.
Оси: X — ширина, Y — глубина/толщина габарита, Z — высота. Модель расположена около начала координат, нижняя точка Z=0.
Дизайн: матовое черное полотно, темная узкая стеклянная вставка, минималистичные декоративные линии, металлическая ручка с небольшими латунными деталями.
Импорт: Blender > File > Import > Wavefront (.obj). OBJ и MTL должны находиться в одной папке.
Примечание: размер 0.370 × 0.240 × 0.580 м необычно мал для реальной входной двери; размеры сохранены точно как указано. Если это масштаб/габарит под конкретный объект, используйте как есть.
