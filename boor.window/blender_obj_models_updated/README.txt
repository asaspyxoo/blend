Обновлённый набор OBJ для Blender
- sliding_door.obj: раздвижная дверь с большими стеклянными створками и тонким металлическим профилем.
- standard_window.obj: вытянутое горизонтальное окно 2,06 x 1,15 м для широкого проёма.
- interior_door.obj: обычная межкомнатная дверь.
- panoramic_window.obj: панорамное окно.
Размеры в метрах, ось Z вверх. Импорт: Blender > File > Import > Wavefront (.obj).
Оставляйте соответствующие .mtl рядом с .obj. Прозрачность стекла в OBJ/MTL поддерживается не всеми импортёрами одинаково; если стекло выглядит непрозрачным, включите Alpha/Transmission в материале Blender.
